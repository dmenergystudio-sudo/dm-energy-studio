DM ENERGY STUDIO - REPOSITORIO PARA SUBIR A GITHUB

QUE HAY AQUI
- index.html : la pagina completa (no hace falta editarla)
- logo.png   : tu logo (ya incluido). Si lo cambias, conserva el nombre logo.png
- designs/   : una carpeta por categoria para tus imagenes
    designs/inicio/                 -> imagenes que se ven en la pantalla de Inicio
    designs/temporadas/             -> 12 meses (enero ... diciembre)
    designs/camisetas/              -> 21 categorias (animes, navidad, halloween ...)
    designs/paises-y-cultura/peru
    designs/tazas-y-termos, shorts-y-pijamas, underwears, celulares,
    designs/hoodies, sublimados, otros, marketplace

COMO LLENARLO
1) Copia tus imagenes dentro de cada carpeta (PNG, JPG, WEBP, GIF o SVG).
   Usa vistas previas livianas: cuadradas y de menos de 300 KB.
   Los PNG originales pesados (con su DPI) NO van aqui: iran en Cloudflare R2.
2) No cambies los nombres de las carpetas ni de las rutas.
3) Puedes borrar el LEEME.txt de cada carpeta cuando subas imagenes.

COMO SUBIRLO
1) Crea un repositorio en GitHub y sube todo: Add file > Upload files.
   Desde el navegador caben unos 100 archivos por subida: sube por partes si hace falta.
2) Conecta ese repositorio en Cloudflare (Pages). NO actives GitHub Pages.
3) Limites de Cloudflare Pages: 20,000 archivos por sitio y 25 MiB por archivo.

IMPORTANTE
Si abres index.html directamente desde tu computadora, las galerias saldran vacias:
es normal. La version final del index.html trae el ajuste para que las galerias
funcionen en Cloudflare.

CAMBIAR PRECIOS, WHATSAPP Y MEDIOS DE PAGO
Abre index.html con un editor de texto y busca el bloque CONFIG (al inicio del script):
  WHATSAPP : numero de pagos y consultas (con codigo de pais, sin +)
  LAUNCH   : true muestra el precio de lanzamiento; false muestra el precio regular
  PLANS    : precios en US$ del plan mensual y anual (regular y lanzamiento)
  PAYMENTS : medios de pago que se muestran (los datos de pago se envian por WhatsApp)

HERRAMIENTAS EN PROCESO (OCULTAS)
En el bloque CONFIG, la lista HIDDEN controla que herramientas no se ven en el menu.
Hoy esta oculta: Studio Creativo DM. Para mostrar una, borra su nombre de la lista.
